# Frontend для Ads Platform

Веб-интерфейс для платформы продажи объявлений.  
Написан на **Vue 3** (без сборки, через CDN) и **Tailwind CSS**.  
Общается с **GraphQL Gateway** (`http://localhost:8080/graphql`).

---

## 🚀 Запуск

1. Убедись, что запущены все сервисы:
   - `make up` (базы данных)
   - `make run-auth`
   - `make run-ad`
   - `make run-gateway`

2. Открой файл `frontend/index.html` в любом браузере.

---

## 🔌 Функциональность

### 🔐 Авторизация
- Регистрация
- Вход / Выход
- JWT-токен хранится в `localStorage`

### 📦 Объявления
- Создание объявления (с выбором категории)
- Просмотр всех объявлений
- Просмотр моих объявлений
- Редактирование своего объявления
- Удаление своего объявления
- Детальная карточка объявления

### 🗂️ Категории
- Выбор категории из выпадающего списка (данные из API)

---

## 🛠️ Технологии

| Компонент | Используемое решение |
|-----------|----------------------|
| **UI** | Vue 3 (CDN) |
| **Стили** | Tailwind CSS |
| **HTTP-клиент** | Fetch API |
| **GraphQL** | Ручные запросы, переменные |
